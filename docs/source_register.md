All raw files are in `data/raw/`. Access date for everything below is **21 Nov 2026** unless stated.
"Method" says exactly how the file was produced, so anyone can repeat it.

**Why some sources were dropped:** Reddit (proposal) - the Reddit pages/API could not be reached from our collection browser, so we replaced it with Rotten Tomatoes audience reviews. TMDb / OMDb (proposal) - both need an API key; Wikidata gives the same metadata plus the TMDb id, so the join still works. YouTube comments - only through the official API (script ready, key needed).
